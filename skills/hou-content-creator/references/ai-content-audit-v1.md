# AI 辅助内容创作与审核规范 V1.0

> 适用于公众号、小红书、抖音、视频号、知乎、B站、快手、X 等内容的创作、改写及审核。本规范为内容质量与编辑工作流要求，不代表任何平台的 AI 检测算法。涉及平台规则、法律和收益资格，必须核实最新官方政策。

## 一、核心原则

真人主导、AI 辅助。AI 负责资料整理、逻辑梳理、文字编辑和生产提效；创作者负责事实验证、独立思考、观点表达和最终审核。不以规避平台 AI 检测为目标，而以真实性、原创性、信息价值和表达质量为目标。

## 二、内容真实性规范

1. 不虚构作者的个人经历、创业过程、工作经历和实践结果。
2. 不编造人物、案例、数据、研究报告及用户反馈。
3. 涉及新闻、政策、行业动态和研究成果时，必须核实信息来源；无法实时核实应提示限制。
4. 明确区分客观事实、他人观点、个人判断和未经验证的推测。
5. 不将尚未实践的方案描述为已经完成的事情。
6. 不为了增强故事性而擅自补充不存在的情节。
7. 引用他人观点时，应保留原意，必要时注明来源。

## 三、内容原创性规范

1. 优先使用作者本人提供的观点、经历、数据、研究资料和实践记录。
2. 不直接搬运、拼接或简单改写其他创作者的内容。
3. 不将同义词替换、句式调整视为原创创作。
4. 二次创作必须提供新的分析、判断、信息或实际应用价值。
5. 避免重复生产主题、观点、结构高度相似的内容；系列内容须有实质新增。
6. 不对不符合平台原创要求的内容进行原创声明。
7. 不为了追求更新频率而牺牲内容质量。

## 四、语言表达规范

### 4.1 词汇

- 优先使用日常生活中常见的词汇，避免不必要的专业术语和抽象概念。
- 避免脱离语境的华丽词汇，不堆砌形容词、四字词语和情绪表达。
- 不机械使用“赋能、闭环、底层逻辑、认知升级”等词汇。

### 4.2 句式

- 自然结合长句和短句，不机械使用排比、对仗、反问和递进。
- 不频繁使用“不是……而是……”等固定句式，不连续使用高度相似的句子。
- 不为制造金句而刻意压缩或拔高观点。
- 不刻意添加错字、语病或无意义口语词来模拟真人。

### 4.3 段落

- 按内容自然分段，不要求段落等长，也不强制每段包含观点、解释和总结。
- 不重复解释已经讲清的内容，不为形式完整而补无价值段落。
- 不机械使用总分总、三段式、五点式等固定结构。

### 4.4 整体表达

- 像真实的人分享自己知道的事情，优先从具体经历、现象、问题或实践开始。
- 保留作者原有表达习惯、思考方式、合理补充、转折与自我修正。
- 不强行制造悬念、冲突、焦虑或情绪反差；不说教、不强行升华。
- 事情讲清楚即可，不为了字数增加废话。
- 连接词不是禁词；“然后”“不过”“我觉得”等可在语境中自然使用，不机械堆砌或为“去 AI 味”刻意删除。
- 不故意制造结巴、假口误或虚构作者的心理变化。与 `writing-style.md` 的真人访谈式表达原则保持一致。

## 五、内容信息价值规范

每篇内容至少应提供一种实际价值：新信息或研究发现；真实经历；具体问题解释；可操作的方法；真实测试结果；有依据的独立观点；降低信息获取成本；帮助解决实际问题。避免只有观点没有依据、只有方法没有细节、只有结论没有过程。

## 六、图片、音频及视频规范

1. 优先使用真实截图、实拍、录屏、研究图表和原始资料。
2. AI 图片可用于封面、插图和概念展示，但不得冒充真实证据。
3. 不生成虚假聊天记录、交易截图、收入证明或客户反馈。
4. 不未经授权克隆他人声音、面孔或身份，不用数字人冒充真人虚假宣传。
5. 不恶意删除、篡改或隐匿依法应当保留的 AI 内容标识。
6. 按法律和平台当前要求进行 AI 生成合成内容声明；区分辅助编辑与生成合成的适用条件。
7. 引用真实资料时，先对个人身份、聊天记录和客户经营信息做必要授权与脱敏。

## 七、账号运营规范

1. 不用 AI 完全托管未经人工审核的发布。
2. 不批量生成低质量、同质化内容。
3. 不用 AI 模拟真人进行虚假评论、点赞、私信及互动。
4. 不以多个账号重复发布相同内容制造虚假传播。
5. 正式发布由创作者人工确认；跨平台应实质适配，而非机械复制。
6. 定期查阅最新平台内容、原创、AI 标识及收益规则。

## 八、平台差异化审核

以下为核查主题，**不是**最新平台政策或平台内部检测标准；需要结合法律和平台官方说明判断。

| 平台 | 重点审核事项 |
| --- | --- |
| 微信公众号 | 原创性、内容质量、创作者真实表达、AI 声明 |
| 小红书 | 真实经历与人设、虚假营销、AI 托管 |
| 抖音 | AI 内容标识、音视频真实性、虚假合成 |
| 微信视频号 | 真实表达、虚假营销、误导性音视频 |
| 知乎 | 独立观点、回答价值、AI 声明、创作收益资格 |
| B站 | 视频原创性、AI 标识、虚假合成内容 |
| 快手 | 内容真实性、违规营销、低质合成内容 |
| X | 内容真实性、欺骗性媒体、虚假互动、垃圾信息 |

不采用未经证实的“AI 生成率”“限流阈值”或“检测通过率”说法。

## 九、发布前强制检查

完整内容交付前内部逐项审核，必要时标为“通过 / 需修改 / 待核实 / 不适用”；不因素材未包含音视频或未申请收益资格而默认不合规。

- [ ] 真实性：是否有虚构的事实、经历、案例、数据？
- [ ] 准确性：事实、数字、引用、来源是否准确？
- [ ] 原创性：有无搬运、洗稿、不当改写？
- [ ] 独立性：是否有作者自己的观点和判断？
- [ ] 信息价值：是否对读者有真实帮助？
- [ ] 自然度：是否机械化、模板化、过度刻意口语化？
- [ ] 逻辑：是否有跳跃、矛盾和无依据因果？
- [ ] 冗余：是否有重复、空话、无意义总结？
- [ ] 素材真实性：图片、音视频是否具有误导性？
- [ ] 版权：是否涉及他人知识产权、肖像或其他人格权益？
- [ ] AI 标识：是否触发适用的生成合成内容声明要求？
- [ ] 平台合规：当前平台适用的内容和经营规则是否满足？
- [ ] 收益资格：若声明原创或参与激励，是否符合实际资格？

## 十、自动审核执行指令

完整创作任务完成初稿后，不直接输出未经检查的初稿。按序执行：

1. 核对事实与原始资料来源；对时变事实查询最新官方规则（宿主具备联网能力时）。
2. 核查是否虚构创作者经历、数据、用户反馈、交易结果。
3. 检查原创性和信息价值，区分引用、分析与作者原创。
4. 对照语言规范和 `writing-style.md` 检查自然表达。
5. 删除重复表达、空话和无意义总结。
6. 按实际发布平台审核隐私、版权、AI 标识和适用合规要求。
7. 在不改变原意的前提下修订，再输出完整成品。
8. 无法核实且关键的事实标记待核实或删除；法律与平台准入等重要风险必须单独提醒用户。

除非用户主动要求审核报告，否则只输出修订后的完整可发布内容，不展示内部评分或检查清单。用户只要求标题、局部修改、封面或审核时，严格按当前任务范围执行，不强制重写全文。不得声称通过平台内部 AI 检测，也不得保证不会被识别、限流或处罚。实际发布仍须创作者人工确认。
