# 事实核查与来源

## 信息分类

写作前把关键陈述分为：用户明确提供的亲历；可核实事实；带来源的数据；创作者观点；基于证据的推断；计划；未知。只有前三类可以作为确定事实使用，观点和推断要保留语气，计划不能写成结果。

## 核查顺序

1. 优先原始材料、官方文档、原始研究、监管公告和产品发布说明。
2. 核对发布日期与事件发生日期，确认数据口径、样本、单位、地区和适用时间。
3. 复算简单计算，写清假设。区分收入与利润、咨询与成交、下载与活跃用户。
4. 对时变信息在任务当下重新查询；宿主不能联网时明确说明未实时验证。
5. 来源冲突时说明差异，不强行得出确定结论。

引用应紧邻所支持的陈述，链接到原始页面。不得伪造 URL、报告名、作者、发布日期或引用原话。找不到证据时，删除该陈述、改为个人判断，或标记待确认。

事实核查降低错误风险，但不替代法律、医疗、财务等专业意见。高风险主题应提醒用户进行专业复核。
