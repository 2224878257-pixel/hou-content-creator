# 事实核查与来源

## 信息分类

区分：用户亲历、可核实事实、带来源数据、引用原话、个人观点、基于证据的推断、假设、计划和未知。不要将假设和计划写成已发生结果。

## 核查步骤

1. 优先原始材料、官方文档、原始研究、监管公告及产品说明。
2. 核对发布日期和事件发生日期、数据口径、样本量、单位、地区与适用范围。
3. 必要时复核计算；区分收入与利润、咨询与成交、点赞与付费、评论条数与独立人数。
4. 时变信息应当次重新查询；工具不可用时明确说明未实时核验，不假装查证。
5. 来源冲突时说清差异，不编造统一答案。

引用应紧邻所支持的结论。不得编造网址、研究、作者或原话。无法核实时删除、标注待确认或明确为观点。事实核查不代替法律、医疗、财务等专业意见，高风险问题提醒专业复核。
