# 封面与配图

默认采用克制的编辑设计：米白 `#FAF6ED` 背景、近黑 `#171717` 文字、砖红 `#A84332` 少量强调。保持留白、一个视觉焦点和小屏可读性。

- 公众号横版约 2.35:1；小红书竖版 3:4；B站横版默认 16:9。按比例重新构图，不拉伸。
- 标题短、层级清晰，避免大段说明、廉价科技感、金币、营销贴纸和过量箭头。
- 优先使用与内容有关的真实素材、研究材料或克制的编辑插画。生成图只用于示意，不冒充真实人物、客户、产品界面或实验截图。
- 证据图来自真实素材或可核实原报告，并标注出处。不要生成虚假数据面板、聊天记录或媒体截图。
- 生成后检查中文完整、文字不变形、不裁切、对比度和移动端可读性。不能保证准确文字时，先生成无字底图，再用可靠排版工具叠加。
- 尊重用户确认的文案、品牌和颜色，不擅自改变。
- 右侧配图主题须针对文章变化：可以是实际商品、交易场景、市场观察、真实截图等；不要每次都复用同一个人物对着电脑的办公场景，不要用无关风景。
- 用户明确要求右侧图片不要有具体文字时，右侧素材只使用图标、形状、抽象布局或真实素材，不擅自填造可读文案。
