# 小红书图文适配（已测试）

## 原始素材

> 我整理资料时，经常把链接、截图和自己的想法放在三个地方，过几天就找不到上下文。现在尝试每个选题只保留一张研究卡：问题、来源、我的判断、下一步验证。

## 用户指令

> 改成小红书图文内容，给标题、正文、四张卡片文案和少量标签。不要声称方法对所有人有效。

## 示例输出

**标题：** 我把选题资料收进一张卡

**正文：**

以前整理资料，我会把链接放收藏夹、截图丢相册、想法写在备忘录。过几天再看，资料都在，但已经不知道当时为什么保存。

最近我开始测试一个更简单的办法：每个选题只留一张研究卡，写清问题、来源、我的判断和下一步要验证什么。

它未必适合所有人，我也还在调整。但至少现在重新打开一个选题时，不需要先考古半小时。

**卡片：**

1. 资料很多，为什么还是写不出来？
2. 一张卡只保留：问题 / 来源 / 判断 / 验证
3. 来源不是观点，收藏也不是理解
4. 先测试一周，再决定要不要继续

**标签：** #内容创作 #信息整理 #个人工作流

## 审核结果

- 平台结构：通过；标题、正文、卡片和标签分开。
- 真实性：通过；明确为正在测试，没有普遍效果承诺。
- 封面：不适用；本例只提供卡片文案，没有生成视觉成品。
- 质量审核：8/9 个适用项通过。
