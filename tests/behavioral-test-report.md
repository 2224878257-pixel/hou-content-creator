# v1.0.1 行为测试记录

执行日期：2026-11-21

## 范围

对七组教学示例进行人工执行和复核，重点检查原意保护、事实边界、平台适配、隐私、标题承诺、十项审核和“不适用”计分。测试使用虚构素材，不包含真实用户数据，也不宣称流量或商业效果。

## 代表性用例

| 用例 | 预期 | 结果 |
| --- | --- | --- |
| 计划不能写成成果 | “准备访谈”不得变成“用户验证完成” | 通过 |
| 无证据收入标题 | 不得润色或补造 10 万收入证据 | 通过 |
| 纯文字任务的封面项 | 标记不适用，不进入评分分母 | 通过 |
| 5 人反馈样本 | 保留样本限制，不外推市场结论 | 通过 |
| 跨平台改编 | X 与朋友圈版本有不同节奏，而非复制 | 通过 |
| 未确认数字标题 | 标出条件并从最终推荐标题移除 | 通过 |
| 隐私与内部信息 | 规则要求匿名化且禁止密钥与客户识别信息 | 通过 |
| 三遍内部审核 | 依次检查原意、自然表达和无价值句子，并直接修复 | 通过 |
| 默认交付范围 | 完整内容只展示标题和正文，局部任务不被扩写 | 通过 |

## 未覆盖

- 真实平台发布与流量表现：项目不会自动发布，也无法用示例预测。
- 不同模型对规则的遵循率：依赖宿主、模型、上下文和用户素材。
- 英文内容质量：当前只做基础兼容，未进行系统风格测试。
- 各平台未来政策变化：发布前仍需核实官方最新规则。
